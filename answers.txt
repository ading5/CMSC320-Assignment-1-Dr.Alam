Answer: We are testing out new features and want an easy way to test features while still being able to rollback the changes if it goes wrong.

Q3: What is the difference between merging and rebasing?

Answer: Merging will bring all changes into the branch, while rebasing will patch the code as if all the changes in the branch were made on the latest commit.
